# AI Configuration Showcase

## What We Built

A completely rebuilt web configurator that uses Google's Gemini AI to automatically analyze photos of school schedules and generate configuration files.

## Live Demo Flow

### Step 1: User Visits /ai-config
Beautiful gradient UI with drag-and-drop upload zone

### Step 2: Upload Schedule Photo
User uploads any photo of their school schedule:
- Handbook page
- Website screenshot
- Printed schedule
- Planner photo

### Step 3: AI Analysis (10 seconds)
Gemini Vision API analyzes the image and extracts:
```json
{
  "school_start": "09:05",
  "school_end": "15:20",
  "num_periods": 6,
  "period_times": {
    "1": "09:25",
    "2": "10:20",
    "3": "11:15",
    "4": "12:40",
    "5": "13:35",
    "6": "14:30"
  },
  "period_names": {
    "1": "Math",
    "2": "English",
    "3": "Science",
    "4": "History",
    "5": "Spanish",
    "6": "Art"
  },
  "has_ab_day": true,
  "has_lunch": true,
  "lunch_start": "12:05",
  "lunch_end": "12:35",
  "has_advisory": true,
```

### Step 4: User Reviews
Clean card-based UI shows:
- School start/end times
- Number of periods
- Period length
- Lunch time
- Schedule type (A/B day detected)

If AI is uncertain about anything, shows warning:
```
⚠️ Please verify these items:
- Period 4 name unclear in image
- Advisory days not specified
```

### Step 5: Interactive Chat
User can ask AI questions:
```
User: "What time is lunch?"
AI: "Lunch starts at 12:05 PM and ends at 12:35 PM, giving you a 30-minute lunch period."

User: "Do I need Canvas?"

```

### Step 6: Additional Configuration
User fills in:

- WiFi networks (1+ networks)

## Technical Implementation

### Backend (Flask)
```python
@app.route('/api/analyze-schedule', methods=['POST'])
def analyze_schedule():
    # Get image from request
    image_file = request.files['image']
    image_bytes = image_file.read()
    
    # Call Gemini AI
    response = client.models.generate_content(
        model='gemini-2.0-flash-exp',
        contents=[
            types.Part.from_bytes(
                data=image_bytes,
                mime_type=image_file.content_type
            ),
            types.Part.from_text(text=prompt)
        ]
    )
    
    # Parse and return structured data
    analysis = json.loads(response.text)
    return jsonify({
        "status": "success",
        "analysis": analysis
    })
```

### Frontend (Vanilla JS)
```javascript
async function analyzeImage() {
    const formData = new FormData();
    formData.append('image', uploadedImage);
    
    const response = await fetch('/api/analyze-schedule', {
        method: 'POST',
        body: formData
    });
    
    const result = await response.json();
    displayAnalysis(result);
}
```

### AI Prompt Engineering
Smart prompt that:
- Requests specific JSON format
- Asks for 24-hour time conversion
- Identifies A/B day patterns
- Detects advisory periods
- Finds lunch times
- Lists uncertainties
