Build Your Own Timagotchi

Complete step-by-step guide to building your schedule display

What You'll Need

Item Description Where to Buy Price
Raspberry Pi Zero WH With pre-soldered GPIO headers Adafruit, PiShop, Amazon $10-15
Waveshare 1.44" LCD HAT 128x128 pixel display with joystick Waveshare, Amazon $15-20
MicroSD Card 8GB or larger (Class 10) Any electronics store $5-10
Battery Bank (optional) Any USB power bank Any electronics store $10-20

Total Cost: $40-65

Step 1: Hardware Assembly

  1. Install Raspberry Pi OS

    Download Raspberry Pi Imager from raspberrypi.com

    Flash Raspberry Pi OS (32-bit) to your microSD card

    During setup, configure WiFi and enable SSH if desired

  2. Attach the Display HAT

    Carefully align the Waveshare LCD HAT with the GPIO pins on your Pi Zero

    Press down gently but firmly until fully seated

    Note: No soldering required if you have the WH model!

  3. Power It Up

    Insert the microSD card into your Pi Zero

    Connect a micro USB cable to the Pi's power port

    Wait 30-60 seconds for boot

Step 2: Enable SPI Interface

The display uses SPI communication. You need to enable it:

sudo raspi-config
  1. Navigate to: Interfacing Options → SPI → Yes
  2. Reboot when prompted

Step 3: Install Timagotchi Software

# Clone the repository
git clone https://github.com/broseph9972/Timagotchi
cd Timagotchi/Code

# Run the automated installer
chmod +x install.sh start.sh
./install.sh

# Reboot
sudo reboot

Step 4: Configure Your Schedule

After reboot, your Timagotchi will display a 5-digit code on screen.

  1. Visit this website on your phone or computer
  2. Enter the 5-digit code shown on your Timagotchi
  3. Fill out the configuration form:
    • School start/end times
    • Period lengths and passing time
    • Canvas LMS credentials (optional)
    • WiFi networks
    • Theme preference
  4. Click "Send to Timagotchi"
  5. Your device will sync automatically and restart

Step 5: Auto-Start on Boot

The installer sets up a systemd service for automatic startup:

# Check status
sudo systemctl status schedule-display

# View logs
sudo journalctl -u schedule-display -f

# Restart service
sudo systemctl restart schedule-display

Optional: Battery Power

To make your Timagotchi portable:

  1. Get any USB battery bank
  2. Connect to Pi Zero's power port
  3. A 10,000mAh battery will last 20+ hours

Tip: Configure time sync mode to "on_boot" so the clock stays accurate even without constant internet access.

Controls

Joystick

  • Up/Down: Navigate menus
  • Left/Right: Switch screens, adjust settings
  • Center Press: Select (hard to press, use Right as alternative)

Function Keys

  • Key1: Jump to Main Page
  • Key2: Jump to Grades
  • Key3: Jump to Settings

Troubleshooting

Display Not Working

  • Verify SPI is enabled: lsmod | grep spi
  • Check HAT is fully seated on GPIO pins
  • Re-run installer: cd ~/Timagotchi/Code && ./install.sh

Can't Get Configuration Code

  • Check internet connection: ping google.com
  • Manually run configuration: python3 configure_schedule.py
  • Check backend URL is set correctly

Canvas Grades Not Showing

  • Verify API token is correct
  • Check Canvas URL format: https://school.instructure.com
  • Ensure token has proper permissions in Canvas settings
