About Timagotchi

A school schedule display system for Raspberry Pi Zero WH

What is Timagotchi?

Timagotchi is a Pi Zero scheduler that tells you how much time you have left in school. It's a portable, battery-powered device that displays your current period, progress through the day, and integrates with Canvas LMS to show your grades.

The project combines hardware hacking, Python programming, and web development to create a practical tool for students. The name is a playful nod to the Tamagotchi virtual pets, but instead of feeding a digital creature, you're staying on top of your schedule!

Project History

This project started as a simple idea: "What if I could see my current class period at a glance?" From there, it evolved into a full-featured schedule display system with Canvas integration, themes, games, and more.

The project is open source and constantly evolving. Community contributions have added features like A/B day scheduling, stopwatch functionality, and this web configuration portal.

Key Features

  • Schedule Display: Shows current period, time remaining, and progress bars
  • A/B Day Support: Automatic or manual A/B day scheduling with preset rotation
  • Canvas Integration: View grades and assignments from Canvas LMS
  • Themes: Multiple pre-configured color themes to choose from
  • Custom Phrases: Configurable messages that appear based on current period
  • WiFi Management: Configure multiple WiFi networks for home and school
  • Stopwatch: Built-in timer for timing activities
  • Web Configuration: Easy setup via this website (no command line required!)

Target Hardware

  • Board: Raspberry Pi Zero WH
  • Display: Waveshare 1.44" LCD HAT (128x128 pixels)
  • Operating System: Raspberry Pi OS (tested on Bookworm & Trixie)
  • Power: Battery bank with USB cable (optional for portability)

Technology Stack

  • Backend: Python 3, Flask (this website)
  • Pi Software: Python 3, Pillow (PIL), NumPy, SPI, GPIO
  • Display Driver: ST7735S LCD driver (Waveshare)
  • Canvas API: Requests library for HTTP/REST integration
  • Frontend: HTML5, CSS3, Vanilla JavaScript
  • Deployment: Render, Railway, or Heroku
