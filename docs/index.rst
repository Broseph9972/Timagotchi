Overview
--------

Timagotchi is a compact Pi Zero scheduler that displays:

- Current school period and time remaining
- Progress bars (multiple modes)
- Canvas LMS grades and assignments
- A/B day schedule support
- Built-in games (Tetris, Doom raycaster)
- Customizable themes and phrases
