# Usage Guide

## Controls

### D-Pad Navigation

- **Up/Down**: Navigate menu items, move in games
- **Left/Right**: Navigate between screens, turn in games, adjust settings
- **Center Press**: Select item (hard to press - use **Right** as alternative)

### Function Keys

- **Key1** (top right): Navigate to Main Page
- **Key2** (middle right): Navigate to Grades
- **Key3** (bottom right): Navigate to Settings

## Menu Navigation

### Main Navigation

Access via **Key1**, **Key2**, **Key3** sidebar buttons:

1. **Main Page** - Animated character with schedule info
2. **Grades** - Canvas grades and assignments
3. **Settings** - Themes, time, A/B day, stopwatch

### Settings Submenu

- **Theme**: Choose from multiple color themes
- **Progress Bar**: Change progress bar visualization mode
- **Set Time**: Manually adjust system time
- **A/B Day**: Toggle between auto/manual A/B day scheduling
- **Stopwatch**: Built-in timer
- **Developer**: Access secret menu (Konami code)
- **Update**: Check for updates (if configured)
- **Restart**: Restart the application

## Secret Menu

Enter the Konami code on the Developer screen:

**↑ ↑ ↓ ↓ ← → ← →**

Unlocks:
- **Tetris**: Play classic Tetris
- **Doom**: PyDoom launcher (if installed)
- **Shitty Doom**: Built-in raycaster FPS
- **Run Custom Script**: Execute custom_script.py

## Game Controls

### Tetris

- **Up**: Rotate piece
- **Left/Right**: Move piece
- **Down**: Drop faster
- **Center**: Hard drop
- **Key1/2/3**: Exit to menu

### Doom Raycaster

- **Up/Down**: Move forward/backward
- **Left/Right**: Turn
- **Center**: Shoot
- **Key1/2/3**: Exit to menu

## Display Modes

### Main Page

Shows:
- Current period name and time remaining
- ASCII art character (changes based on period)
- WiFi status
- Theme-colored sidebar

### Schedule View

- Current and next periods
- Time in current period vs total period duration
- Progress bar (configurable mode)

### Grades

- List of courses from Canvas
- Current grade percentage for each
- Assignment details

### Clock

Full system clock display with large time.
