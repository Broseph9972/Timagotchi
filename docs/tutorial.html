How It Works

guide to using your Timagotchi

Getting Started

Read the docs if you haven't already

The Waveshare 1.44" LCD HAT includes a joystick and three function keys:

  • Joystick Up/Down: Navigate menu items vertically
  • Joystick Left/Right: Navigate menu items horizontally, turn in games, adjust settings
  • Joystick Center Press: Select item (can be hard to press - use Right as alternative)
  • Key1 (top right): Navigate to Main Page from anywhere
  • Key2 (middle right): Navigate to Grades from anywhere
  • Key3 (bottom right): Navigate to Settings from anywhere

[Image: Button layout diagram]

Step 3: Main Page Overview

The Main Page displays:

  • Animated Character: Shows current status with Pwnagotchi-inspired ASCII faces
  • Current Period: Displays which class you're in or "passing" between periods
  • Time Remaining: Shows how much time is left in the current period
  • Progress Bar: Visual representation of time (mode changeable in Settings)
  • WiFi Status: Small indicator box showing connection status
  • Custom Phrases: Context-aware messages based on current period

[Image: Main page screenshot]

Navigating Menus

Main Navigation

The right sidebar shows your current location and available pages:

  • Main Page (Key1): Schedule and character display
  • Grades (Key2): Canvas grades and assignments
  • Settings (Key3): Themes, time, A/B day, stopwatch, and more

Use the joystick or function keys to navigate between these main sections.

[Image: Navigation sidebar]

Viewing Grades

If you've configured Canvas integration during setup:

  1. Press Key2 or navigate to the Grades page
  2. Select a course from the list
  3. View current grade percentage and assignments
  4. Browse assignments by grade/date
  5. Use "Update Grades" to refresh data from Canvas

[Image: Grades screen]

Settings Menu

Access various customization options:

  • A/B Day: Toggle between auto/manual A/B day scheduling
  • Theme: Choose from multiple color themes
  • Progress Bar: Change visualization mode (time in class, time in day, lunch countdown)
  • Set Time: Manually adjust system time using on-screen controls
  • Stopwatch: Built-in timer with start/stop/reset
  • Developer: Enter Konami code for secret menu

Themes

Customize the look of your Timagotchi:

  1. Navigate to Settings → Theme
  2. Use joystick to browse available themes
  3. Select a theme to apply it immediately
  4. Your choice is saved automatically

Themes change colors for background, text, accents, sidebar, and dividers.

Understanding Schedule Features

A/B Day Scheduling

If your school uses alternating A/B day schedules:

  • Auto Mode: Device automatically tracks which day type it is
  • Manual Mode: Manually set A or B day in Settings → A/B Day
  • Preset Rotation: Schedule cycles through configured presets

[Image: A/B day setting]

Progress Bar Modes

Change how time is visualized:

  • Time in Class: Shows progress through current period
  • Time in Day: Shows progress through entire school day
  • Lunch Countdown: Shows time remaining until/during lunch

Change mode in Settings → Progress Bar

Battery Life

To maximize battery life on portable power:

  • The Pi Zero draws minimal power (~100-150mA)
  • Expected runtime: 8-12 hours on 8kmah battery
  • Dim screen brightness in Settings for longer life
  • consider powering from a phone battery if you have no battery bank.

Common issues

  • Buttons not responding: Verify GPIO permissions and connections
  • Wrong schedule: Run configure_schedule.py to reconfigure
  • Canvas not loading: Check canvas_config.json has valid API token
  • Time sync issues: Ensure WiFi connection or manually set time
