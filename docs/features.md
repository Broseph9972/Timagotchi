# Features

## Display & Navigation

- **Main Page**: Character with schedule information
- **Schedule View**: Current period with time remaining
- **Progress Bars**: Multiple visualization modes
- **Clock View**: Full system clock
- **Theme System**: Customizable color schemes
- **WiFi Status**: Indicator for network connectivity

## Schedule Management

- **A/B Day Support**: Automatic or manual scheduling
- **Advisory Period**: Optional homeroom support
- **Passing Time Detection**: Shows transitions between periods
- **Custom Phrases**: Context-aware messages by period

## Canvas Integration

- **Grade Display**: View current grades from Canvas LMS
- **Assignment List**: Browse assignments by course
- **Course Details**: See course names and percentages
- **Secure Configuration**: API token stored locally

## Games

- **Tetris**: Classic tile-dropping game
- **Doom Raycaster**: Built-in FPS engine

## Settings & Customization

- **Theme Selector**: Choose from multiple themes
- **Progress Bar Modes**: Switch visualization styles
- **Time Settings**: Manual time adjustment
- **Stopwatch**: Built-in timer
- **Developer Mode**: Access secret menu
